底圖提案：純程式紋理 v1

六個方向全部是 SVG／CSS 程式碼生成——顏色鎖 v2.1 品牌色、濃度壓在文字可讀範圍、黑白列印會退成均勻淺灰不干擾。已避開前輪否決的六種風格（關卡地圖、等高線、剪紙、瑞士幾何、階梯、筆刷）。每張示範框模擬衛教單上的文字區。

A｜漫畫網點
少年漫畫 screentone：對角雙色網點漸層，戰鬥感最直接，濃度可逐級調。

A 漫畫網點 戰鬥感 ★★★

radial-gradient 網點＋mask 漸層。黑白列印＝標準網點灰，反而像印刷網花，最耐印。

B｜集中速度線
從角落放射的漫畫集中線——「本週重點在這裡」的視線引導，天生適合放標題區。

B 集中速度線 戰鬥感 ★★★

SVG 線段，粗細隨機交錯。只佔一個角、版面大片留白，資訊密的衛教單最安全。

C｜向上 Chevron
連續向上的箭頭紋從頁尾往上淡出——「一直在升級」的隱喻，低調不搶戲。

C 向上 Chevron 低調 ★★★

兩層 linear-gradient 拼出箭頭，濃度最低的一款；適合當全頁滿版基底紋。

像素角標＋血條（可拿來當「本週任務進度條」實際欄位）。復古遊戲機感，30–49 歲主力族群的童年語彙。

純 CSS grid 像素。血條不只是裝飾——可直接變成任務達成度的書寫欄位。

E｜六角戰術網格
RPG 技能樹／戰術地圖的蜂巢格，點亮的格子＝已解鎖的習慣。

E 六角網格 科技感 ★★★

SVG pattern。可延伸玩法：每冊點亮不同數量的格子，暗示旅程進度。

F｜能量斜紋＋路徑點
斜切的雙色能量帶＋頂部虛線路徑（起點→現在→目標），把「旅程」畫成一條線而不是一張地圖。

F 能量斜紋 動感 ★★★

repeating-linear-gradient 斜紋＋SVG 虛線路徑。路徑點可對應五關，每冊亮的點不同。
